1. Deskripsi Repository
Repository adalah tempat penyimpanan untuk menyimpan dan mengelola berbagai file proyek perangkat lunak yang memungkinkan developer untuk mengelola kode sumber, berkolaborasi dengan tim, serta melacak perubahan dalam sebuah proyek.

2. Tujuan atau kegunaan repository
Tujuan atau Kegunaan 
1. Version Control (Kontrol Versi), Developer dapat melacak perubahan yang dilakukan pada kode mereka;
2. Kolaborasi Tim, Memungkinkan banyak developer bekerja pada proyek yang sama tanpa harus khawatir kehilangan perubahan yang mereka buat;
3. Penyimpanan Terpusat, Semua file proyek disimpan di satu tempat, sehingga memudahkan akses bagi anggota tim.

Rangkuman Materi
========================= Prompt Engineering =========================
Prompt Engineering -> Cara merancang instruksi agar AI memberikan jawaban yang tepat, relevan, dan layak untuk digunakan.

Prompt adalah instruksi yang diberikan kepada model untuk mendapatkan hasil tertentu.
Prompt (without context dan with context).
Dalam beberapa kasus, prompt without context dapat membuat AI halusinasi dan tidak mengerti dengan konteks yang diberikan sehingga menghasilkan output yang tidak sesuai.

Good prompt structure : Role, task, context, dan format.

Keuntungan Prompt Engineering
1. Meningkatkan performa AI model 
2. Mengurangi bias dan respon yg offensive
3. Meningkatkan kontrol dan predictability
4. Memberikan pengalaman yg lebih baik

========================= Git/Hub =========================
Git adalah control system yang melacak siapa, kapan, dan apa saja yang sudah dirubah dalam suatu file.
Git -> diciptakan oleh Linus Torvalds pada tahun 2005.

Git Workflow
1. Working directory/tree -> salinan dari satu versi proyek yang sedang dikerjakan.
2. Staging area -> file yang umumnya berada di dalam direktori Git dan berfungsi untuk menyimpan informasi mengenai perubahan apa saja yang akan dimasukkan ke dalam commit berikutnya.
3. Git directory -> tempat Git menyimpan metadata dan object database dari sebuah proyek.

Perbedaan Git dan Github
Git    : untuk melacak dan mengelola perubahan kode secara lokal.
Github : Platform untuk menyimpan repository Git secara online dan mendukung kolaborasi.

Beberapa contoh Git Command
git init -> untuk memulai repo baru
git add. -> untuk memindahkan file ke stagging area
git commit -m 'message' -> untuk menyimpan file ke repository
